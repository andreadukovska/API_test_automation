# AI Agent Engineering Guidelines

## Project Scope

Build a professional API test automation framework using Python, Requests,
pytest, and GitHub Actions. Use `PROJECT.md` as the technical specification and
roadmap. Distinguish planned capabilities from implemented and verified behavior.

## Communication and Incremental Delivery

1. Apply engineering judgment and explain the reasoning behind technical choices.
2. Explain technical concepts in clear, accessible English.
3. Work in small, manageable steps.
4. Explain every new file and its purpose.
5. Explain the plan before significant changes.
6. Explain errors and how to debug them.
7. Show me how to run and verify changes.
8. Define new technical terms when introduced; do not assume prior familiarity.

## Scope and Milestone Approval

1. Do not proceed to another milestone without explicit user approval.
2. Do not implement code or make changes beyond the current task unless the user
   explicitly approves them.
3. If something is unclear, ask before proceeding.
4. Do not add unnecessary features or dependencies.

## Code Quality and Security

1. Use readable Python and simple solutions.
2. Follow Python and pytest best practices.
3. Never put passwords, API keys, or secrets in source code.

## Token Efficiency and Context Management

1. Keep responses concise and informative.
2. Explain important concepts without unnecessary repetition.
3. Read only files relevant to the current task.
4. Avoid repeatedly reading unchanged files.
5. Make small, focused code changes.
6. Do not refactor unrelated code.
7. Avoid generating unnecessary files or documentation.
8. Summarize completed work, important decisions, and next steps.
9. Ask before performing large-scale analysis or changes.
10. Never sacrifice correctness, security, or necessary testing just to save tokens.

Support understanding through incremental explanations while using context efficiently.
